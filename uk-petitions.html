UK Parliament Petitions Dashboard

  • Go to dashboard

Summary

The UK Petitions Dashboard has been designed as a tool to help MPs and their staff make better use of publicly available data on UK e-petitions, by presenting key statistics in a more accessible way.

Background

The UK Government and Parliament Petitions website hosts numerous petitions, each calling for a change in Government policy or legislation. Unlike other petition websites, such as Change.org, any petition that has over 10,000 signatures receives a written response from the Government, while those that have over 100,000 signatures are considered for debate in Parliament.

The UK Petitions website hosts data on the number of signatures for each petition, including a breakdown by constituency. That data can be accessed by navigating to each individual petition page, but there is currently no easy way of gaining an overview of that data, especially at the constituency level.

Data on the number of signatures for each petition is publicly available at the constituency level, but it is difficult to get an overview of petiton data relating to a specific constituency. This information would help MPs better understand and represent the views of their constituents. The purpose of this project is to make this information more easily accessible to MPs and their staff.

Motivation behind the UK Petitions Dashboard

The aim of the UK Petitions Dashboard is to make that data more accessible for MPs and their staff. Petition data serves as a useful temperature check to gauge how pertinent various issues are in any given constituency and how that compares to another.

While there are some shortcomings to petition data (detailed below), there is a clear case for making better use of it. Firstly, as mentioned above, petition data is used by the Petitions Committed to decide whether to hold a debate on that topic or not. If it is used to make a decision on parliamentary agenda, it is worth MPs and their staff having a better idea of emerging trends from petition data. Secondly, public engagement with e-petitions is high, with some garnering millions of signatures.1 It is therefore important to be aware of the issues being raised through petitions. Finally, given that petition data is so readily available, it is a missed opportunity to not make better use of it.

There are several web applications that already exist, created by individuals or organisations, independently of the Government and Parliament. For example, there is the UK Petitions Tracker and Parallax's UK Petitions Explorer.

However, these petition trackers are not usually designed specifically for MPs and their staff. The UK Petitions Dashboard seeks to fill this gap. As such, the Dashboard will:

  • Primarily provide a constituency level overview
  • Make sure insights are compact and concise, giving a snapshot view of key statistics; and
  • Include metrics to help MPs stay ahead of emerging trends, for example by highlighting petitions that are likely to reach the threshold for debate weeks before it reaches that point. [Currently in development].

Planned updates to dashboard

The UK Petitions Dashboard is currently in its early stages. There are plans to develop further features to make it a more useful tool. Planned updates include:

  • Allowing MPs and their staff to sign up to a mailing list that provides a monthly overview of key statistics
  • Using archived daily statistics to create a forecast of the petitions that are likely to meet the threshold for debate
  • Develop better metrics, for example, to flag petitions which petitions are following an unusual trajectory

For any other suggestions, please email ukpetitionsdashboard@gmail.com.

Note on data

Shortcomings of petition data

There are a few shortcomings to petition data that should be taken into consideration when using the dashboard:

  • There is currently no mechanism to stop one person signing the same petition twice, which means the number of signatures may be inflated.
  • Since these petitions are held online, it is likely to be underrepresenting the views of older constituents.
